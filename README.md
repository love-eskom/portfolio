## Overview

This website serves as my professional portfolio and central platform for documenting and presenting my engineering work.

As a Computer Science student, I am developing practical skills across software development, network infrastructure and cybersecurity. Rather than relying solely on certifications or coursework, this portfolio emphasizes hands-on projects, technical implementation, engineering decisions and continuous learning.

The website provides a central place to explore my projects, technical notes, background and professional interests.

## Design Philosophy

The portfolio follows a minimal, technical and editorial design direction.

- **Minimalism** — Avoid unnecessary visual elements and distractions.
- **Clarity** — Prioritize readable content, clear navigation and structured information.
- **Consistency** — Maintain a unified visual identity across pages and project documentation.
- **Technical identity** — Use typography, subtle colour accents and structured layouts to reflect an engineering-focused brand.
- **Substance over decoration** — Highlight real implementations, technical reasoning and documented results.

## Development

The website is built using standard HTML, CSS and JavaScript without a frontend framework.

### Run locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
```

Navigate into the project directory:

```bash
cd portfolio
```

Open `index.html` in your browser, or use a local development server such as the VS Code Live Server extension.

### Deployment

The website is hosted using Cloudflare Pages and connected to its GitHub repository for deployment.

Updates pushed to the configured branch are automatically deployed.
